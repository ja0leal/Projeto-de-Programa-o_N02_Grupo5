Sobre o Projeto: Agenda Grupo 5

O que é o projeto e o problema que ele resolve.

O "Agenda Grupo 5" é uma aplicação web desenvolvida em Spring Web destinada a otimizar o gerenciamento de tarefas e agendamentos para pequenas equipes, como grupos de estudo acadêmicos ou times de desenvolvimento ágil.

O Problema e Nossa Solução

Ferramentas de mercado consolidadas (como Trello, Asana ou Google Calendar) são, por vezes, excessivamente complexas ou genéricas para as necessidades específicas de grupos menores. Observou-se que essa complexidade pode gerar atrito na adoção da ferramenta, levando a uma subutilização ou ao abandono da mesma.

Nossa proposta justifica-se pela necessidade de preencher essa lacuna, oferecendo uma solução leve (lightweight), intuitiva e centralizada, focada exclusivamente nos elementos essenciais da gestão de tarefas colaborativas: visibilidade de prazos e atribuição de responsabilidades.

Tecnologias Utilizadas

A stack técnica que fundamenta o projeto.

  • Backend: Java (JDK 17) com Spring Boot e Spring Web MVC.
  • Frontend (View): Renderização no lado do servidor (SSR) com o modelo engine Thymeleaf.
  • Estilização: Tailwind CSS (metodologia utility-first) para um design responsivo.
  • Banco de Dados: Microsoft SQL Server.
  • Acesso a Dados: Spring JdbcTemplate, para controle direto e granular sobre as consultas SQL.
  • Gerenciamento e Build: Apache Maven.
